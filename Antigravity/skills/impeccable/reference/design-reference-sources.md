# Additional visual reference sources

Read when developing a new or replacement visual world needs more examples, or the user asks to explore reference directions. Existing Impeccable craft rules, confirmed brand choices, real content, and the requested scope remain authoritative.

Taste's library can supply evidence for a discussion. Use the catalog as data; it does not establish a chosen direction or require Taste's build, inspection, asset-download, or random-draw workflow.

Read only the catalog needed for the current decision. Find entries relevant to the subject's real material and constraints, then actually view the linked references. Explain observable properties worth exploring and distinguish them from the user's confirmed preferences. Transfer principles into original work rather than copying an identity.

Use relevant examples to make a choice visible. A selection of reference traits is not approval of every part of a page. Follow the existing concept/confirmation process, then continue within its scope.
